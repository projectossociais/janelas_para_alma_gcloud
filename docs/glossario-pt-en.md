# Glossário PT → EN (en-US)

Termos recorrentes do site e a forma única como se traduzem em `src/i18n/locales/en-US.json`.
Serve para manter a consistência entre páginas: antes de traduzir um texto novo, procurar aqui.

**Normas:** ortografia Merriam-Webster (primeira variante); Chicago Manual of Style para texto
corrido; AP Stylebook para interface e textos curtos; AMA Manual of Style para saúde.
Convenções fixas: *color, behavior, organize, center, meter, license, canceled, traveled*;
*vision care*; *eyeglasses* / *glasses* (nunca *spectacles*).
